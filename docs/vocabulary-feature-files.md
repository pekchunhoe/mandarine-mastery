## Corrected findings and limits

- Application: a pronunciation refresh enhanced underlying essay text after a guided step redraw. Scope enhancement to the open dialog; exact before/after state checks now pass.
- Application: reverse Tab could leave the native dialog for browser chrome. Explicit first/last focus wrapping now passes keyboard tests.
- Stale tests: old 564-record counts, substring count waits, absent-grade assumptions and old essay-title/selection expectations failed against the expanded workbook and current essay architecture. Use authoritative counts, anchored waits, isolated optional-field records and current essay-title data.
- Test harness: plain voice objects were incompatible with native utterance setters; a controlled utterance test double now verifies Mandarin dispatch and Cantonese rejection. Native dialog close cleanup is asynchronous, so tests wait for the close-event cleanup.
- The original workbook, existing IDs, all prior field values and their order remain preserved. No deletion override was used.
- Responsive results are automated Edge viewport checks, including reduced keyboard space. Physical mobile keyboards and audible voice quality were not manually tested.
